# AI-Assisted Engineering

AI is a cross-cutting engineering tool used throughout all 26 weeks.

## Time model

A practical target is **about 30–45 minutes per week of deliberate AI-workflow learning**.

This time is embedded inside the existing module budgets rather than added on top. Across 26 weeks it represents roughly 13–20 hours.

Ordinary use of AI while coding, debugging, or documenting is not separately counted as “AI study time.”

The distinction is:

- **deliberate AI learning:** intentionally practicing a workflow or evaluating how an agent/tool should be used
- **normal AI use:** using the tool naturally as part of engineering work

## Goals

- improve planning and problem decomposition
- accelerate routine implementation without surrendering ownership
- strengthen testing and edge-case discovery
- improve code, SQL, and architecture review
- practice agent-based GitHub workflows
- learn when external tools and MCP integrations are actually useful

## Working principles

1. Understand the task before delegating it.
2. Ask for a plan when the change is non-trivial.
3. Review generated code and SQL before accepting it.
4. Run tests and validate behavior.
5. Treat AI suggestions as proposals, not authority.
6. Prefer small reviewable changes.
7. Keep repository instructions and project context explicit.
8. Use AI to increase engineering quality, not just typing speed.
9. Be able to explain every accepted result without relying on generated text.
