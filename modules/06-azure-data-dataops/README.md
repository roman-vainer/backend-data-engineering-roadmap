# Module 06 — Azure Data Platform & DataOps

**Weeks:** 20–23  
**Time:** 32 hours

## Learning Goals

Deploy and operate the already-understood data architecture in the Microsoft cloud ecosystem using repeatable engineering practices.

## Minimal Practical Path

The detailed module plan will choose one coherent deployable path from the core ecosystem:

- Azure SQL
- Azure Storage / ADLS Gen2
- Azure Data Factory
- Azure Databricks
- Key Vault where appropriate
- monitoring/logging
- GitHub Actions for selected CI/CD steps

Not every service is required at equal depth. The goal is one understandable end-to-end system.

## DataOps Topics

Git, environments, configuration, secrets, automated tests, CI/CD, deployment, monitoring, access control, security boundaries, cost awareness, Docker where it serves the chosen path, and basic Infrastructure as Code concepts.

## Change Management

Practice how:

- database/schema changes
- configuration changes
- data-contract changes

are versioned and promoted between environments.

## Scope Control

The module does not attempt to create a second specialization in DevOps, Terraform, Docker, security, or Azure platform administration.

Microsoft Fabric is optional ecosystem awareness, not a second core stack.

## Practice

Move selected project components to Azure and automate the smallest useful build/test/deployment path. Demonstrate configuration/secrets handling and basic monitoring rather than adding services for their own sake.

## Definition of Done

The module is complete when the learner can explain and demonstrate how code, data, schema/configuration changes, secrets, deployment, monitoring, and access control fit together in one Azure-based data solution.

## Planning

The detailed weekly plan and Issues are created shortly before this module begins.
