# Module 06 — Azure Data Platform & DataOps

**Weeks:** 20–23  
**Time:** 32 hours

## Learning Goals

Deploy and operate the data architecture in the Microsoft cloud ecosystem using repeatable engineering practices.

## Core Platform

Azure SQL, Azure Storage, ADLS Gen2, Azure Data Factory, Azure Databricks, Key Vault concepts, monitoring/logging.

## DataOps Topics

Git, environments, configuration, secrets, CI/CD, GitHub Actions, Docker, automated tests, deployment, monitoring, access control, security boundaries, cost awareness, basic Infrastructure as Code.

Microsoft Fabric is optional ecosystem awareness, not a second core stack.

## Practice

Move selected components from local development to Azure and automate selected build/test/deployment steps.

## Definition of Done

The module is complete when the learner can explain and demonstrate how code, data, configuration, secrets, deployment, monitoring, and access control fit together in an Azure-based data solution.

Detailed weekly tasks and Issues will be added later.
