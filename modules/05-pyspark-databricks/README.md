# Module 05 — PySpark & Databricks

**Weeks:** 16–19  
**Time:** 32 hours

## Learning Goals

Understand distributed processing well enough to build and troubleshoot a production-style Spark workflow.

## Topics

Spark architecture, DataFrames, transformations/actions, lazy evaluation, partitions, joins, aggregations, shuffle, caching concepts, Spark SQL, PySpark, performance, schema handling, Delta Lake, batch processing, basic streaming, Databricks compute/workspace/jobs concepts.

## Practice

Implement distributed transformations and investigate how partitioning, joins, shuffle, and execution behavior affect performance.

## Definition of Done

The module is complete when the learner can build a PySpark workflow, explain its execution at a high level, identify common performance problems, and run it in Databricks using a production-oriented structure.

Detailed weekly tasks and Issues will be added later.
