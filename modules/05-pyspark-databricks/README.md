# Module 05 — PySpark & Databricks

**Weeks:** 16–19  
**Time:** 32 hours

## Learning Goals

Understand distributed processing well enough to build and troubleshoot one production-shaped Spark workflow.

## Practical Core

Spark architecture, DataFrames, transformations/actions, lazy evaluation, partitions, joins, aggregations, shuffle, Spark SQL, PySpark, performance fundamentals, schema handling, batch processing, Delta Lake, and one Databricks workflow.

## Secondary Scope

- caching/persistence concepts
- basic streaming concepts
- broader workspace/compute/jobs features beyond what the chosen workflow needs

Streaming remains awareness/basic concepts rather than a second pipeline specialty.

## Execution Environment

The detailed module plan must state the environment before practice starts:

- early Spark mechanics may be practiced locally if that reduces setup friction
- Databricks practice uses one available workspace/environment
- Azure deployment/operations are deferred to Module 06

## Practice

Implement distributed transformations over project data and investigate how partitioning, joins, shuffle, and execution behavior affect performance. Finish with one coherent Databricks workflow rather than multiple disconnected feature demos.

## Definition of Done

The module is complete when the learner can build a PySpark workflow, explain its execution at a high level, identify common performance problems, and run one production-oriented Delta/Databricks flow.
