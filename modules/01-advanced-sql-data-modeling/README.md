# Module 01 — Advanced SQL & Data Modeling

**Weeks:** 1–4  
**Time:** 32 hours  
**Primary database:** Microsoft SQL Server

## Learning Goals

- move beyond CRUD-oriented SQL
- reason about query performance and execution plans
- understand indexes, statistics, transactions, isolation, locking and concurrency
- model robust OLTP data
- translate operational models into analytical fact/dimension structures

## Topics

Complex JOINs, aggregation, CTE/recursive CTE, window functions, constraints, normalization/denormalization, execution plans, SQL Server indexes, statistics, transactions, isolation, locking, deadlocks, concurrency, OLTP modeling, star schema, facts/dimensions, SCD.

## Practice

Hands-on work will use SQL Server and include query-writing, plan analysis, indexing experiments, concurrency scenarios, and data-model design.

## Definition of Done

The module is complete when the learner can independently analyze a non-trivial query, explain its execution plan, justify indexing choices, reproduce and explain common concurrency behavior, design an OLTP model, and derive a suitable analytical model from it.
